The bee and the bug nobody caught 🐛

The bee asked an AI coding assistant for a function that returns the second largest distinct number in a list. It wrote:

def second_largest(nums):
    largest = float('-inf')
    second = float('-inf')
    for num in nums:
        if num > largest:
            second = largest
            largest = num
        elif num > second:
            second = num
    return second

All her tests passed: [4, 8, 2, 6] → 6, [10, 5, 3, 1] → 5. Which input exposes the bug, and how do you fix it?

Reveal answer

Try [8, 8, 6]: the second 8 is not bigger than largest, but it is bigger than second, so the function returns 8 instead of 6. Duplicates of the maximum are never filtered out.

Fix: change the second condition to elif largest > num > second:. It still runs in one pass with O(1) extra memory, no sorting needed. Also return None when there is no second distinct value.

Algorithms🟠 Medium

The bee's backpack 🎒🍯

The bee's bag holds up to 10 kg. Each nectar jar can be taken once, and only whole:

  • A: 6 kg, value 30
  • B: 3 kg, value 14
  • C: 4 kg, value 16
  • D: 2 kg, value 9
  • E: 5 kg, value 20

Which jars give the maximum value? And does always grabbing the best value-per-kg jar work?

Reveal answer

A + C: exactly 10 kg, value 46.

Greedy by value per kg fails here: it takes A (5/kg), then B (4.67/kg), reaching 9 kg and value 44, with no room for anything else. This is the 0/1 knapsack problem, and dynamic programming finds the true optimum.

What comes next?

3, 6, 11, 18, 27, 38, ?

Find the next number, and explain why.

Reveal answer

51. The gaps are 3, 5, 7, 9, 11, so the next gap is 13. Put another way, the n-th term is n² + 2, and 7² + 2 = 51.

Logic🟠 Medium

Two ropes, 45 minutes 🔥

You have two ropes. Each takes exactly one hour to burn, but unevenly, so half a rope doesn't mean half an hour. You also have matches.

How do you measure exactly 45 minutes?

Reveal answer

Light rope 1 at both ends and rope 2 at one end. Rope 1 burns out after 30 minutes. At that moment, light the other end of rope 2: its remaining half hour now burns in 15 minutes. 30 + 15 = 45.
